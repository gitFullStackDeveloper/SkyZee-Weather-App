# SkyZee-Weather-App

SkyZee is a web-based weather application that provides real-time weather information with a modern and responsive interface.

## Features

* Live weather information
* City weather search
* Interactive weather map
* Rain prediction and alerts
* Real-time weather updates
* Responsive web interface

## Tech Stack

* Frontend: React.js
* Backend: Laravel
* Database: SQLite

## Project Structure

* SkyZee-Weather-App/
* ├── react/       # React.js Frontend
* └── laravel/     # Laravel Backend & API
